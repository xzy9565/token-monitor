## 💡 Why Token Monitor?

Modern AI software engineers increasingly balance multiple AI coding tools and subscriptions: **Claude Code, Cursor, Codex, Antigravity CLI, Command Code**, alongside pay-as-you-go providers like **DeepSeek, OpenRouter, or Modal**.

This causes **Subscription Fragmentation**:
- Different rolling windows: 5-hour sessions, 7-day rolling ceilings, monthly billing cycles.
- Hidden rate limits that trigger mid-flow right before a crucial deadline.
- Wasteful spending: expiring quotas reset unused while you pay out-of-pocket on secondary API wallets.

**`token-monitor` solves this.** It is a single, zero-friction terminal dashboard that actively monitors your balances and calculates your **optimal burn sequence** so you maximize what you've already paid for.

---

## ⚡ Key Features

### 🔥 1. "Burn-First" Rate-Limit Scheduler
Instead of just reporting static numbers, `token-monitor` ranks subscriptions by urgency:
- Compares rolling session deadlines (e.g. 5h window) against durable weekly cycle resets (7d).
- Factors in remaining headroom and time-to-reset.
- Suggests exactly which model or subscription you should burn first before its quota expires.
- Automatically demotes exhausted accounts to the bottom of the stack.

### 📊 2. Actuarial Local Token Ledger
Press `2` (or `t`) to switch to the full-featured accounting ledger:
- **Zero-Synthetic Parsing**: Reconciles actual token records directly from local JSONL and SQLite session stores generated by Claude Code, Cursor, Codex, and Antigravity.
- **Granular Token Breakdowns**: Input, Output, Cache-Read, Cache-Write, and Reasoning tokens accounted for separately.
- **Strict Valuation Engine**: Calculates exact API-equivalent retail value ($) and capital efficiency metrics (`M tokens / $`).
- **Instant Temporal Slicing**: Seamlessly browse `Today`, `Last 24h`, `Last 7d`, `Last 30d`, and `All Time` with `h` / `l` or `←` / `→`.

### ⚡ 3. Sub-Microsecond Performance (80 Nanoseconds)
Built in pure **Rust** on top of **Ratatui**:
- Precomputed aggregation cache renders complex windows containing 25,000+ local session records in **~80 nanoseconds** per frame.
- Smooth scrolling and sub-frame responsive key navigation.
- Asynchronous non-blocking network collectors running off the render thread — a slow or rate-limited provider will never freeze your terminal or tmux pane.

### 🛡️ 4. Absolute Local Privacy & Zero Probe Tokens
- **No synthetic probes**: Never sends dummy completion requests to "test" your balance — zero wasted tokens.
- **Local credential store**: All secrets are stored in `~/.config/token-monitor/credentials.json` with strict `0600` (owner-only) permissions.
- **Automatic masking**: Account emails and IDs are securely masked by default in both TUI and JSON output (`p***@example.com`).

## 🚀 Quick Start

### 🍺 Homebrew (macOS, Recommended)

Install precompiled native binaries in seconds via Homebrew:

```bash
brew install xzy9565/tap/token-monitor
```

### ⚡ One-Line Install (Cargo)

If you already have Rust installed, install directly into `~/.cargo/bin/token-monitor`:

```bash
cargo install --git https://github.com/xzy9565/token-monitor
```

### 🛠️ Build from Source

```bash
git clone https://github.com/xzy9565/token-monitor.git
cd token-monitor
cargo build --release
```

Run the compiled binary directly:

```bash
# Launch interactive live TUI (defaults to live collection + 60s background refresh)
./target/release/token-monitor

# Single-shot snapshot to stdout (perfect for scripts / statuslines)
./target/release/token-monitor --once

# Local Token Ledger view (past 30 days)
./target/release/token-monitor --consumption --days 30

# Offline demonstration mode with mock fixtures
./target/release/token-monitor --mock
```

## ⌨️ Interactive Controls

| Key | Action |
|:---:|:---|
| `1` / `2` / `3` | Switch views: **[1] Limits**, **[2] Ledger**, **[3] Config** |
| `h` / `l` or `←` / `→` | Switch Time Window in Ledger (`Today` ⇄ `24h` ⇄ `7d` ⇄ `30d` ⇄ `All Time`) |
| `j` / `k` or `↓` / `↑` | Move cursor selection up / down |
| `Enter` | Open detailed drill-down modal for selected provider, client, or model |
| `/` | Open inline interactive fuzzy search / filter |
| `m` | Toggle rank metric (Total Tokens vs. API-Equivalent USD) |
| `p` | Open native credential manager to configure keys or session tokens |
| `a` | Filter by providers requiring attention |
| `c` | Filter by credit grants and wallets |
| `r` | Force an immediate background refresh of all collectors |
| `Esc` / `q` | Close modal / quit |

## 🛡️ Philosophy & Disclaimer

- **Built for personal flow**: `token-monitor` was created to scratch a personal itch and bring order to a fragmented multi-model workflow.
- **Read-only by design**: It never modifies external configurations, writes shell startup scripts, or submits synthetic completion prompts.
- **Best-effort maintenance**: Issues and pull requests are warmly welcomed! However, ongoing maintenance is provided strictly on a best-effort basis without formal SLA.
